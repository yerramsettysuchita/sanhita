Closing the gaps, not just listing them

The problem statement asks for gaps to be identified and remediated. Finding one is a report. Closing one is a piece of work somebody owns, with a deadline, that ends in evidence. Nothing here closes because a person says it is fixed. A task closes when the certified rule is run again and the engine returns no finding.
